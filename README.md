# Net Switch

[English](README_EN.md)

Net Switch 是一个开源的网络配置切换客户端，帮助经常在家庭、公司、实验室等不同网络之间移动的人，减少反复修改 IP、网关和 DNS 的麻烦。

## 为什么开发它

笔记本连接不同 Wi-Fi 时，网络要求往往并不相同：家里通常使用 DHCP，公司或实验室却可能要求固定 IP、指定网关和 DNS。手动修改不仅繁琐，也很容易忘记恢复，最终出现“Wi-Fi 已连接但无法上网”的情况。

Net Switch 希望把这些重复操作变成一次配置、按网络自动处理。你只需要为常用 Wi-Fi 保存规则，之后切换网络时便能快速回到合适的配置。

## 它能帮你做什么

- 查看当前 Wi-Fi、IPv4、子网掩码、网关和 DNS。
- 按 Wi-Fi 名称保存不同的网络配置规则。
- 连接熟悉的 Wi-Fi 后自动应用对应规则。
- 离开固定网络后按你的选择保持现状或恢复 DHCP。
- 随时暂停自动切换、手动应用规则或恢复 DHCP。
- 通过系统托盘快速操作，并可在登录电脑后自动启动。
- 使用中文或英文控制面板，默认显示中文。
- 在本机查看最近操作结果和日志，便于发现网络问题。

## 适合谁

- 经常往返家庭、办公室和客户现场的开发者。
- 需要连接服务器、NAS、摄像机或实验设备的用户。
- 需要在 DHCP 与固定 IPv4 配置之间切换的网络管理员。
- 希望避免每次都进入系统设置手工修改网络的人。

你可以从 [GitHub Releases](https://github.com/putyy/netswitch/releases) 获取发布版本。

## 隐私

Net Switch 在本机运行，不需要账号，也不依赖云端服务。控制面板、配置和日志均保留在你的电脑上。

项目仍在持续完善。欢迎通过 Issue 反馈使用中遇到的问题和希望支持的网络场景。
